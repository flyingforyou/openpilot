# Tesla Model X HW1 gap 연동 및 comma 4 UI 표시 구현 지시서

## 1. 작업 목적

다음 기능을 `/home/compiler/openpilot`의 현재 XNOR Curve 기반 코드에 구현한다.

1. Tesla Model X HW1 스티어링 휠에서 설정한 차간거리 Gap 1~7을 CAN에서 읽는다.

2. 읽은 Gap 값을 Longitudinal MPC의 `tFollow`에 실제 반영한다.

3. Gap을 크게 변경했을 때 즉시 강한 감속이 발생하지 않도록 Carrot 방식처럼 `tFollow` 증가 방향만 천천히 반영한다.

4. 운전자가 Gap을 변경하면 comma 4 화면 중앙 상단에 `GAP 1`부터 `GAP 7` 중 현재 값을 표시하고 정확히 약 1초 후 자동으로 숨긴다.

5. 현재 primary lead가 Radar와 매칭된 앞차인지 Vision only 앞차인지 comma 4 화면에 지속적으로 표시한다.

6. Carrot 전체 Long Control은 포팅하지 않는다. 이번 작업 범위는 Tesla Gap 연동, `tFollow` 적용, UI 표시로 제한한다.

## 3. 최종 동작 정의

Tesla Gap과 `tFollow` 매핑은 다음과 같이 한다.

```text
Gap 1 = 1.10초
Gap 2 = 1.20초
Gap 3 = 1.30초
Gap 4 = 1.40초
Gap 5 = 1.50초
Gap 6 = 1.60초
Gap 7 = 1.75초
```

규칙:

1. Tesla Gap이 1~7 범위로 정상 수신되면 기존 Driving Personality의 고정 `tFollow` 대신 Tesla Gap 값을 우선 사용한다.

2. Tesla Gap을 작은 값으로 변경할 때는 새로운 `tFollow`를 즉시 적용한다.

3. Tesla Gap을 큰 값으로 변경할 때는 목표거리가 갑자기 증가해 즉시 브레이크가 걸리지 않도록 초당 0.10초만 증가시킨다.

4. 최초 유효 Gap 수신 시에는 현재 차량 설정을 즉시 적용한다. 최초 수신에도 slew limiter를 적용하지 않는다.

5. CAN 값이 `255`, SNA이거나 알 수 없는 값이면 마지막 유효 Gap을 유지한다.

6. 시동 후 유효 Gap을 한 번도 받지 못했으면 기존 personality 기반 `tFollow`로 fallback한다.

7. Gap 변경 UI는 최초 값 수신 때 표시하지 않는다. 이전 유효 Gap에서 다른 값으로 변경된 경우에만 표시한다.

8. Lead source UI 의미는 “현재 앞차 인식 데이터의 출처”다. Longitudinal MPC의 최종 제어 source와 혼동하지 않는다.

```text
leadOne.status == false
표시 없음

leadOne.status == true and leadOne.radar == true
RADAR 표시

leadOne.status == true and leadOne.radar == false
VISION 표시
```

기존 구조에서 사용되지 않은 다음 ordinal을 먼저 확인한다. 공개 XNOR Curve 기준으로는 `@7`이 사용 가능하지만, 로컬 HEAD에서 중복 여부를 반드시 확인한다.

```capnp
struct CruiseState {
  enabled @0 :Bool;
  speed @1 :Float32;
  speedCluster @6 :Float32;
  available @2 :Bool;
  standstill @4 :Bool;
  nonAdaptive @5 :Bool;

  # 0 means unavailable or not implemented.
  # Tesla Model S/X legacy uses values 1 through 7.
  gapAdjust @7 :UInt8;

  speedOffsetDEPRECATED @3 :Float32;
}
```

요구사항:

~ `0`은 unknown 또는 미지원

~ `1~7`은 Tesla 화면의 Gap 단계

~ 기존 필드를 변경하거나 ordinal을 재사용하지 않는다

~ 기존 로그와의 backward compatibility를 유지한다

```python
TESLA_DTR_RAW_TO_GAP = {
  0: 1,
  33: 2,
  66: 3,
  100: 4,
  133: 5,
  166: 6,
  200: 7,
}


def decode_tesla_gap(raw_gap: int) -> int:
  """Convert Tesla DTR_Dist_Rq raw value to gap level.

  Returns:
    1 through 7 for a valid Tesla gap.
    0 for SNA or an unknown value.
  """
  return TESLA_DTR_RAW_TO_GAP.get(int(raw_gap), 0)
```

`CarState.__init__()`에 마지막 유효 Gap 저장 변수를 추가한다.

```python

```

`update_legacy()`에서 Model X HW1 방향지시등을 읽는 동일한 `STW_ACTN_RQ` 메시지에서 `DTR_Dist_Rq`를 읽는다.

권장 위치는 cruise state 처리 이후 또는 Model X 방향지시등 처리 근처다.

```python
if self.CP.carFingerprint == CAR.TESLA_MODEL_X_HW1:
  raw_gap = int(cp_chassis.vl["STW_ACTN_RQ"]["DTR_Dist_Rq"])
  decoded_gap = decode_tesla_gap(raw_gap)

  if decoded_gap != 0:
    self.cruise_gap = decoded_gap

  ret.cruiseState.gapAdjust = self.cruise_gap
else:
  ret.cruiseState.gapAdjust = 0
```

주의사항:

~ `255`를 Gap 7로 해석하지 않는다

~ unknown 값에서 `self.cruise_gap`을 0으로 되돌리지 않는다

~ Model X HW1 외 차량의 동작은 변경하지 않는다

~ `STW_ACTN_RQ`는 이미 `TurnIndLvr_Stat` 때문에 사용 중이므로 새로운 CAN bus나 별도 parser를 만들지 않는다

### 7.1 Gap별 tFollow 상수

기존 상수 근처에 추가한다.

```python
TESLA_GAP_T_FOLLOW = {
  1: 1.10,
  2: 1.20,
  3: 1.30,
  4: 1.40,
  5: 1.50,
  6: 1.60,
  7: 1.75,
}

T_FOLLOW_RISE_RATE = 0.10  # seconds of tFollow per real second
```

### 7.2 기존 personality 함수 유지

기존 `get_T_FOLLOW()` 호출을 사용하는 테스트와 다른 차량이 있으므로 기존 함수 호환성을 유지한다.

```python
def get_T_FOLLOW(personality=log.LongitudinalPersonality.standard, gap_adjust=0):
  if gap_adjust in TESLA_GAP_T_FOLLOW:
    return TESLA_GAP_T_FOLLOW[gap_adjust]

  if personality == log.LongitudinalPersonality.relaxed:
    return 1.75
  elif personality == log.LongitudinalPersonality.standard:
    return 1.45
  elif personality == log.LongitudinalPersonality.aggressive:
    return 1.25
  else:
    raise NotImplementedError("Longitudinal personality not supported")
```

### 7.3 순수 slew helper 추가

테스트할 수 있도록 순수 함수로 분리한다.

```python
def limit_t_follow_increase(current: float, target: float, dt: float) -> float:
  """Apply target immediately when decreasing, rate limit only increases."""
  if target > current:
    return min(target, current + T_FOLLOW_RISE_RATE * dt)
  return target
```

### 7.4 MPC 내부 상태 추가

`LongitudinalMpc.reset()` 또는 적절한 초기화 위치에 추가한다.

```python
self.t_follow = get_T_FOLLOW()
self.gap_adjust_initialized = False
self.last_gap_adjust = 0
```

Gap 상태 갱신 helper를 클래스에 추가한다.

```python
def update_t_follow(self, personality, gap_adjust: int) -> float:
  valid_gap = gap_adjust in TESLA_GAP_T_FOLLOW

  if not valid_gap:
    self.t_follow = get_T_FOLLOW(personality)
    self.gap_adjust_initialized = False
    self.last_gap_adjust = 0
    return self.t_follow

  target_t_follow = get_T_FOLLOW(personality, gap_adjust)

  # First valid vehicle gap should be applied immediately.
  if not self.gap_adjust_initialized:
    self.t_follow = target_t_follow
    self.gap_adjust_initialized = True
  else:
    self.t_follow = limit_t_follow_increase(
      self.t_follow,
      target_t_follow,
      self.dt,
    )

  self.last_gap_adjust = gap_adjust
  return self.t_follow
```

### 7.5 update signature 변경

기존:

```python
def update(self, radarstate, v_cruise,
           personality=log.LongitudinalPersonality.standard):
  t_follow = get_T_FOLLOW(personality)
```

변경:

```python
def update(self, radarstate, v_cruise,
           personality=log.LongitudinalPersonality.standard,
           gap_adjust=0):
  t_follow = self.update_t_follow(personality, int(gap_adjust))
```

이후 기존 코드의 다음 부분은 그대로 `t_follow`를 사용한다.

```python
cruise_obstacle = (
  np.cumsum(T_DIFFS * v_cruise_clipped)
  + get_safe_obstacle_distance(v_cruise_clipped, t_follow)
)

self.params[:, 4] = t_follow
```

중요:

~ Acados 모델의 parameter dimension은 변경하지 않는다

~ `lead_t_follow`는 이미 runtime parameter이므로 generated solver 재생성은 원칙적으로 필요하지 않다

~ personality의 jerk factor는 이번 변경에서 유지한다

~ Gap은 원하는 추종 시간만 변경하며 acceleration limits, comfort brake, stop distance는 변경하지 않는다

~ Carrot의 dynamic `jLead`, traffic stop, lane change gap 축소는 이번 작업에 포함하지 않는다

```python
def _draw_lead_source(self, rect: rl.Rectangle) -> None:
  if self._lead_source is None:
    return

  text = self._lead_source
  font_size = 36
  height = 68
  padding_x = 30

  text_size = measure_text_cached(self._font_semi_bold, text, font_size)
  width = max(190, text_size.x + padding_x * 2)

  x = rect.x + rect.width - UI_CONFIG.border_size - width
  y = (
    rect.y
    + UI_CONFIG.border_size
    + UI_CONFIG.button_size

  if text == "RADAR":

  else:

  badge_rect = rl.Rectangle(x, y, width, height)

  rl.draw_rectangle_rounded_lines_ex(
    badge_rect,
    0.45,
    10,

  text_pos = rl.Vector2(

    0,
```

```python
  limit_t_follow_increase,
)
```

테스트를 추가한다.

```python
@pytest.mark.parametrize(
  "gap, expected",
  [
    (1, 1.10),
    (2, 1.20),
    (3, 1.30),
    (4, 1.40),
    (5, 1.50),
    (6, 1.60),
    (7, 1.75),
  ],
)
def test_tesla_gap_t_follow(gap, expected):
  assert get_T_FOLLOW(
    log.LongitudinalPersonality.standard,
    gap_adjust=gap,
  ) == pytest.approx(expected)


def test_invalid_gap_uses_personality():
  assert get_T_FOLLOW(
    log.LongitudinalPersonality.standard,
    gap_adjust=0,
  ) == pytest.approx(1.45)


def test_t_follow_decrease_is_immediate():
  assert limit_t_follow_increase(1.75, 1.10, 0.05) == pytest.approx(1.10)


def test_t_follow_increase_is_rate_limited():
  result = limit_t_follow_increase(1.10, 1.75, 0.05)
  assert result == pytest.approx(1.105)
```

기존 personality 기반 following distance 테스트가 모두 통과해야 한다.

~ Gap이 unknown일 때 임의로 Gap 1을 선택하지 않는다

~ `DTR_Dist_Rq == 255`를 Gap 7로 처리하지 않는다

~ Gap 1에서도 FCW, AEB 또는 danger zone 제약을 약화하지 않는다

~ MPC의 `LEAD_DANGER_FACTOR`를 이번 변경에서 낮추지 않는다

~ UI 표시를 위해 Params 파일을 매 프레임 읽거나 쓰지 않는다

~ UI 표시를 위해 새로운 daemon이나 메시지를 만들지 않는다

~ Carrot 저장소 파일을 복사해서 XNOR 구조를 대규모로 변경하지 않는다
